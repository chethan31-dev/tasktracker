# 🚀 Task Management System

A full-stack task management application with authentication, CRUD operations, filtering, and analytics.

---

## 🌐 Live Demo

- Frontend: https://your-vercel-link.vercel.app  
- Backend API: https://tasktracker-s8dn.onrender.com  

---

## ✨ Features

- 🔐 User authentication (JWT-based signup/login)
- 📋 Create, read, update, delete tasks
- 🔄 Mark tasks as completed
- 🔍 Filter by status and priority
- 🔎 Search tasks by title
- 📊 Analytics dashboard (total, completed, pending, percentage)
- 📱 Responsive UI

---

## 🛠 Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Authentication: JWT
